RSQ Skill Router — Vault Architecture

Skills live in the vault. Only relevant ones are symlinked into active memory.

■ Vault

  • • Read-only source of truth
  • • All 576 skills live here
  • • Organized by field
  • • Never modified by router

■ Router Engine

  • • Matches intent → skills
  • • Keyword + field scoring
  • • Multi-field routing
  • • ~800 token overhead

■ Active Directory

  • • Symlinks only (never copies)
  • • 5–15 skills at a time
  • • Always-on skills protected
  • • Agent reads from here
