RSQ Skill Router — Component Architecture

Eight modules. One CLI. Install once, route forever.

Indexer + Matcher

  • • Scans every SKILL.md in vault
  • • Extracts name + description + body keywords
  • • Weighted Jaccard scoring: name ×3, keywords ×2, desc ×1
  • • Field-level intent signals for fast routing

Vault Manager + Cron

  • • Symlink-only operations — never touches real files
  • • Atomic reconcile: activate before deactivate
  • • 24h sweep auto-vaults newly installed skills
  • • Weekly reports: usage analytics + token savings

Installer + SKILL.md

  • • Auto-detects 11 agent frameworks
  • • Interactive always-on skill picker with numbered menu
  • • curl | bash · pip · npx · manual install paths
  • • SKILL.md: agent auto-runs reconcile every turn
